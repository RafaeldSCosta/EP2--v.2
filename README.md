# ⚓ Batalha Naval - Python (EP2)

> Recriação do clássico jogo Batalha Naval no terminal, desenvolvido como Projeto (EP2) do 1º Semestre.

---

## 📌 Sobre o Projeto

Este projeto consiste na recriação do clássico jogo **Batalha Naval** em Python, rodando de forma interativa diretamente no terminal. 

O objetivo principal foi aprimorar a **lógica de programação** e consolidar o domínio de estruturas fundamentais da linguagem, aplicando na prática conceitos essenciais do início da graduação em Engenharia/Computação.

---

## 🚀 Conceitos e Aprendizados Aplicados

* **Estruturas de Dados:** Uso de listas e dicionários para representar tabuleiros, coordenadas e posicionamento da frota de embarcações.
* **Controle de Fluxo:** Implementação de loops (`while`/`for`) para gerenciar as rodadas do jogo e validações de jogada.
* **Condicionais e Lógica:** Verificação de acertos, tiros na água, posições repetidas e condições de vitória/derrota.
* **Modularização:** Divisão limpa do código entre regras de negócio/funções auxiliares (`funcoes.py`) e o fluxo principal da aplicação (`programa.py`).
